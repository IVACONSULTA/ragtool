# LangSmith Integration Guide

This guide explains how to use LangSmith monitoring and debugging with the SapRagTool.

## 🎯 Overview

LangSmith provides powerful monitoring, debugging, and evaluation capabilities for AI applications. This integration adds comprehensive tracing to your CrewAI RAG agent without requiring any changes to your existing Railway deployment.

## 🚀 Quick Start

### 1. Get LangSmith API Key

1. Sign up at [smith.langchain.com](https://smith.langchain.com/)
2. Go to Settings → API Keys
3. Create a new API key
4. Copy the API key

### 2. Set Environment Variables

Add these to your Railway environment variables or local `.env` file:

```bash
# LangSmith Configuration
LANGSMITH_API_KEY=your_langsmith_api_key_here
LANGSMITH_PROJECT=sap-rag-tool
LANGCHAIN_TRACING_V2=true
```

### 3. Deploy

Deploy your application as usual. LangSmith tracing will be automatically enabled.

## 🛠️ Configuration Options

### Environment Variables

| Variable               | Description       | Default           | Required |
| ---------------------- | ----------------- | ----------------- | -------- |
| `LANGSMITH_API_KEY`    | LangSmith API key | None              | Yes      |
| `LANGSMITH_PROJECT`    | Project name      | `sap-rag-tool`    | No       |
| `LANGCHAIN_TRACING_V2` | Enable tracing    | `true`            | No       |
| `LANGCHAIN_ENDPOINT`   | Custom endpoint   | LangSmith default | No       |

### Configuration in Code

```python
from agents.langsmith_integration import get_langsmith_manager

# Get LangSmith manager
manager = get_langsmith_manager()

# Check if enabled
if manager.is_enabled():
    print("LangSmith tracing is active")

# Get configuration
config = manager.config
print(f"Project: {config['project']}")
```

## 📈 Advanced Features

### Custom Tracing

Add custom traces to your code:

```python
from agents.langsmith_integration import trace_function, log_agent_interaction

@trace_function("my_custom_operation")
def my_function():
    # Your code here
    pass

# Log custom interactions
log_agent_interaction(
    "custom_agent",
    "user input",
    "agent response",
    {"custom_metadata": "value"}
)
```

### Error Logging

```python
from agents.langsmith_integration import log_error

try:
    # Your code
    pass
except Exception as e:
    log_error(e, "my_operation", {"context": "additional_info"})
```

### RAG Operation Logging

```python
from agents.langsmith_integration import log_rag_operation

# Log a RAG search
log_rag_operation(
    "search",
    "user query",
    search_results,
    {"database": "chroma", "collection": "documents"}
)
```

## 🔧 Troubleshooting

### LangSmith Not Working

1. **Check API Key**: Ensure `LANGSMITH_API_KEY` is set correctly
2. **Check Project**: Verify `LANGSMITH_PROJECT` is set
3. **Check Logs**: Look for LangSmith initialization messages
4. **Test Connection**: Use the health endpoint to check status

### Health Check

The `/health` endpoint now includes LangSmith status:

```bash
curl https://your-app.railway.app/health
```

Response includes:

```json
{
  "langsmith": {
    "enabled": true,
    "project": "sap-rag-tool",
    "client_available": true
  }
}
```

### Common Issues

1. **"LangSmith not available"**: Install with `pip install langsmith`
2. **"API key not found"**: Set `LANGSMITH_API_KEY` environment variable
3. **"Client initialization failed"**: Check API key validity and network connectivity

## 📚 API Reference

### LangSmithManager Class

```python
class LangSmithManager:
    def is_enabled(self) -> bool
    def get_client(self) -> Optional[Client]
    def trace_function(self, name: str, **kwargs)
    def trace_async_function(self, name: str, **kwargs)
    def log_rag_operation(self, operation: str, query: str, result: Any, metadata: Dict)
    def log_agent_interaction(self, agent_name: str, user_message: str, agent_response: str, metadata: Dict)
    def log_error(self, error: Exception, context: str, metadata: Dict)
```

### Convenience Functions

```python
# Tracing decorators
@trace_function("operation_name")
def my_function(): pass

@trace_async_function("async_operation")
async def my_async_function(): pass

# Logging functions
log_rag_operation(operation, query, result, metadata)
log_agent_interaction(agent_name, user_message, response, metadata)
log_error(error, context, metadata)
```
